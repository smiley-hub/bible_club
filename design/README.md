# METU Bible Club design concepts

The images in `mockups/` are generated visual proposals, not implemented pages.
All people, photos, event examples, and historical wording are illustrative.
Replace sample content with verified club information before publishing the site.

## Approved direction

- Warm cream, forest green, and muted gold.
- Lora headings and Source Sans 3 body text.
- Public pages: Home, Our Story, Events, Event Details, Photo Album, Get in Touch.
- A visitor-controlled history wheel with previous/next controls.
- Upcoming events and photo albums from past events.
- A private leader area for content editing, built on Django admin.

## Requirements to implement

- Multiple homepage hero photos in a slideshow, with arrows and position dots.
- Pause control if slideshow autoplay is enabled.
- Leaders can upload, replace, reorder, hide, and remove homepage photos.
- Leaders can update event photos, history images, and organizer portraits.
- Support captions and accessibility descriptions for photos.

The Django environment is initialized; these website features are not yet built.
Do not regenerate or edit the approved mockups unless requested.
