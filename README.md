# Bible Club

Django website foundation with a private admin, SQLite for local development,
and local media storage. The public site and event editing will be built next.

## Local development (PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Set a unique `DJANGO_SECRET_KEY` in `.env`. The initial workspace setup already
creates this file with a random key; do not overwrite it when continuing locally.

```powershell
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py createsuperuser
.\.venv\Scripts\python.exe manage.py runserver
```

Open http://127.0.0.1:8000/ and http://127.0.0.1:8000/admin/.
Choose your own admin username and password when running `createsuperuser`.

## Checks

```powershell
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe -m pip check
```

## Storage and deployment

`static/` holds versioned design assets; `media/` holds private-to-Git uploads.
`staticfiles/` is generated by `collectstatic`. SQLite and media need persistent
storage and backups on the live host. Production also needs `DJANGO_DEBUG=False`,
the actual domain in `DJANGO_ALLOWED_HOSTS`, HTTPS, a production application
server, and explicit static/media serving. Django's development server is local only.
